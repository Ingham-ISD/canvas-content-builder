# Canvas Content Builder — Chrome Web Store Listing

## Name

Canvas Content Builder

## Short description

Plan, create, revise, and review Canvas LMS course content with an organization-managed AI assistant.

## Full description

Canvas Content Builder helps authorized educators build clearer, more consistent Canvas courses without moving between separate tools.

Use the teacher-facing chat to plan a course, choose an organization pattern, upload a scope and sequence, or ask for current Canvas guidance. Use the built-in workspaces to create reviewable Canvas build plans, draft and revise pages, turn teacher-provided question documents into Classic Quiz plans, and rebuild selected Canvas items with a consistent approved template.

Key features:

- Course-design chat for units, weeks, chapters, bays/rotations, projects, and hybrid course structures.
- Template gallery with previews of approved Canvas page patterns.
- Build plans for modules, pages, assignments, discussions, and Classic Quizzes; items are designed for teacher review before publishing.
- Page Editor for drafting, inserting, or replacing Canvas Rich Content Editor HTML.
- Assessment Studio for creating reviewable Classic Quiz batches from teacher-provided text documents.
- Bulk Edit and per-item Rebuild tools for consistent course improvements.

Canvas Content Builder is intended for authorized Ingham ISD educators using the organization&rsquo;s Canvas LMS and AI service. It does not independently access Google Drive or Google Docs. Do not submit student records, grades, passwords, API keys, or other confidential information unless your organization has approved that use.

## Store privacy disclosure draft

The extension processes Canvas course content, user prompts, and files only when the educator chooses an AI feature. This material is sent securely to the organization&rsquo;s Google Apps Script proxy and configured Airia AI service solely to provide the requested course-design, content-generation, or revision feature. The extension does not sell user data or use it for advertising.
