Canvas Content Builder Privacy Policy

Effective date: August 17, 2026

Organization: Ingham ISD

Purpose

Canvas Content Builder is an Ingham ISD-managed Chrome extension that helps authorized educators plan, create, revise, and manage instructional content in Canvas LMS. It is intended only for users authorized by Ingham ISD.

Information the extension handles

When a user requests an AI feature, the extension may handle the user’s prompt; files the user chooses to upload; and relevant Canvas course content the user chooses to analyze, generate, revise, or rebuild. This can include page, assignment, discussion, quiz, module, and course-structure information.

The extension uses the educator’s existing Canvas browser session to perform requested Canvas actions. It does not collect the educator’s Canvas password. The extension’s Airia API key is stored only in the organization’s Google Apps Script proxy and is not stored in the extension.

How information is used and shared

Information is used only to provide the requested Canvas Content Builder feature. When the user invokes an AI feature, the relevant material is sent over HTTPS to the organization’s Google Apps Script proxy and then to the organization’s configured Airia AI service for processing. The organization does not use this information for advertising, sale, or interest-based profiling.

Canvas Content Builder does not independently access Google Drive or Google Docs. A Google Drive URL is not read by the extension’s AI service unless the user separately uploads or pastes the relevant content.

User choices and safeguards

Users choose when to send material to an AI feature. The extension presents a data-use notice before the first AI request. Users should not submit student records, grades, IEP/504 information, passwords, API keys, or other confidential information unless Ingham ISD has explicitly approved that use.

AI-generated content is presented for educator review. The user controls whether to create, replace, or publish Canvas content.

Retention and security

Data is transmitted using HTTPS. Ingham ISD manages the Google Apps Script proxy and its Airia configuration. BrainFreeze’s published Privacy Policy states that it retains information for the duration of the applicable agreement and for 30 days after the agreement ends, after which it deletes or anonymizes the information; securely isolated backups and archives may remain until deletion under its retention policy. BrainFreeze may maintain usage and security logs. Actual retention of prompts, model responses, and diagnostic details, as well as administrator access, depends on the Ingham ISD BrainFreeze/Airia tenant configuration. Ingham ISD must confirm those tenant settings, including any limited-duration retention and end-user privacy controls, before broad deployment.

Contact

For questions about this policy or this extension, contact: Ken Turner, ken.turner@inghamisd.org.

Chrome Web Store User Data Policy

Ingham ISD uses extension data only to provide the disclosed educational functionality. It does not sell user data, use it for advertising, or use it for unrelated profiling.
